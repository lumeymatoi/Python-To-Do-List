📝 To-Do List

A simple To-Do List application developed in Python using Tkinter to create the graphical user interface.

The application allows users to add, view, and remove tasks through a simple and intuitive interface.

🚀 Features
✅ Add new tasks
📋 View existing tasks
🗑️ Remove tasks
🖥️ Graphical user interface using Tkinter
🔢 Automatic task numbering
🛠️ Technologies
Python
Tkinter
